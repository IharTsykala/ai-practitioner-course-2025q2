# 🧠 RAG Question Answering System

This project implements a **Retrieval-Augmented Generation (RAG)** pipeline that allows you to ask natural language questions about documents from the [Minneapolis Institute of Art](https://github.com/artsmia/collection) collection. It uses:

- FAISS vector search for retrieval
- OpenAI LLM (gpt-3.5-turbo) for answer generation
- Express API and Swagger docs
- CLI for terminal interaction

---

## 📦 Installation

```bash
git clone https://github.com/IharTsykala/ai-practitioner-course-2025q2.git
cd ai-practitioner-course-2025q2
npm install
```

---

## 🔐 Environment Variables

Create a `.env` file in the project root:

```
OPENAI_API_KEY=sk-...
PORT=8002
```

## 📁 Project Structure

```
.
├── data/                  # Folder with source .json files
├── scripts/               # Scripts to load & embed documents
├── services/              # Core RAG logic
├── routes/                # Express API endpoints
├── server/                # Express app
├── docs/                  # Swagger docs config
├── cli.js                 # CLI entry point
├── testAsk.js             # Manual testing script
└── faiss.index            # Local vector index (autogenerated)
```

---

## 🚀 Commands

### 💾 Load and Embed Documents

```bash
npm run load
```

```bash
npm run embed
```

- Loads all `.json` files from `data/`
- Extracts and chunks content
- Creates embeddings and stores in FAISS (`faiss.index`)

---

### ❓ Ask a Question (CLI)

```bash
rag-cli "Tell me about Japanese ceramics"

[//]: # (rag-cli "Find portraits by female artists")

[//]: # (rag-cli "Show me artworks related to religion")

[//]: # (rag-cli "Find artworks with floral motifs")
```

> ⚠️ Requires `npm link` to register CLI command:

```bash
chmod +x cli.js
npm link
```

---

### 🧪 Test Locally (Scripted)

```bash
npm run test:ask
```

Runs a pre-defined question and logs answer + source docs.

---

### 🌐 Start API Server

```bash
npm start
```

- Starts Express server (default: http://localhost:8002)
- Endpoint: `POST /ask`
- Swagger: [http://localhost:8002/docs](http://localhost:8002/docs)

---

## 📬 API Usage

### `POST /ask`

**Request:**

```json
{
  "question": "Tell me about Japanese ceramics"
}
```

**Response:**

```json
{
  "answer": "Japanese ceramics often feature nature themes...",
  "sources": [
    { "id": 102941 },
    { "id": 105795 },
    ...
  ]
}
```
